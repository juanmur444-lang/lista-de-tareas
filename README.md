# Lista de tareas

Aplicación web sencilla para anotar tareas, marcarlas como completadas y eliminarlas. Hecha con HTML, CSS y JavaScript puro, manipulando el DOM.

**Demo:** https://juanmur444-lang.github.io/lista-de-tareas/

Práctica académica del Tecnólogo en Análisis y Desarrollo de Software (ADSO), SENA.

## Funcionalidades

- Agregar una tarea con el botón **Crear Tarea** o con la tecla **Enter**.
- Aviso si se intenta agregar una tarea vacía.
- Marcar o desmarcar una tarea como completada.
- Eliminar una tarea.

## Tecnologías

- HTML
- CSS
- JavaScript (sin librerías)
- Bootstrap Icons y Google Fonts (Roboto)

## Cómo ejecutarlo

No necesita instalación:

```
git clone https://github.com/juanmur444-lang/lista-de-tareas.git
```

Luego abre el archivo `index.html` en el navegador.

## Qué aprendí

- Crear elementos del DOM con `createElement` y agregarlos con `appendChild`.
- Escuchar eventos de clic y de teclado con `addEventListener`.
- Cambiar estilos con `classList.toggle` para marcar tareas completadas.
- Usar `innerText` para mostrar el texto que escribe el usuario sin interpretarlo como HTML.

## Mejoras pendientes

- Guardar las tareas en `localStorage` para que no se pierdan al recargar la página.
- Permitir editar una tarea.
